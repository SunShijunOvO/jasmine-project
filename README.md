# Internship Tracker · 实习求职管理平台

面向正在寻找实习或校招机会的学生，开发者自己是第一位真实用户。

## 要解决的问题

求职时会接触许多公司和岗位。职位信息、职位描述（JD）、投递状态、笔试、面试和备注容易分散在不同地方，难以持续管理。项目希望帮助用户在一个地方管理求职过程。

上述内容是已知的问题背景，不代表第一版已经承诺实现全部相关功能。具体使用场景、需求和最小可用版本（MVP）将通过后续分析确定。

## 项目目标

在 2026 年 10 月 20 日前，争取完成一个自己真正用得上的基础版本，并亲手经历需求、设计、开发、测试、部署和迭代。项目也将用于 GitHub 与简历展示。

学习方式是导师引导、开发者亲手实现。技术按需引入，基础功能完成后再判断是否需要 AI。
